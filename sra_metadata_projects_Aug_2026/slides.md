# Ten projects to improve SRA metadata

## Available data, method, cost, and the test that settles each one in a week

---

<!-- _class: compact -->

# Background

Sequencing data submitted to public archives is accompanied by a metadata record: organism, tissue, instrument, library preparation. These records are frequently incomplete and sometimes incorrect. Analyses that rely on them inherit those errors.

We have a table linking **136,323 published papers** to the **157,619 archive projects containing data those papers generated**. A paper usually describes its samples in more detail than the archive record does. This gives two possible uses:

- **As an input:** extract the missing values from the paper text.
- **As an answer key:** hide a value the submitter did supply and test whether it can be recovered.

A second reference source requires no paper: **the sequence data itself.** Where the record and the sequence disagree, the sequence is the more reliable of the two.

# Evaluation requirement for every project

Two methods recover missing metadata using the archive alone, with no paper and no model:

**Copy from sibling samples** — take the most frequent value of that field among the other samples in the same project. **Copy from the sample's own title** — many titles carry the value directly:

```text
SAMEA6677308    Kidney_old_rep2
SAMEA6529006    Arundo_collina_Roma_leaf
SAMD00229900    Anolis_allisoni_brain_liver_skin_mix
```

Neither method works everywhere. Where the submitter used an autogenerated title, both fail and the paper is the only remaining source:

```text
SAMN30613431    Model organism or animal sample from Rattus norvegicus
SAMN30613433    Model organism or animal sample from Rattus norvegicus
```

Both baselines must be implemented and reported as the floor before any model result is quoted. Each project is scored on the **residual cells** — those neither method recovers.

A separate prerequisite for any paper-based project: measure **how often the correct value appears in the paper at all.** That is an upper bound on extraction, independent of method. Where the value is not in the text, no reader can recover it.

# A1 · GEO-MIRROR
## Per-sample values lost in the GEO-to-SRA transfer

Datasets submitted to GEO are copied into the BioSample/SRA records used by most downstream tools. Where GEO holds a distinct value per sample, the copied record sometimes carries one value repeated across every sample:

```text
PRJNA175527 (GSE40996) — 24 samples, 5 attribute keys
tissue = "airway smooth muscle layer from airway wall"  on all 24 samples
```

Whether GEO holds a distinct value per sample here is exactly what the project measures.

```stats accent=sky
247,957 | field-and-project combinations | constant across every sample, in 77,508 projects
116,660 | of those came through GEO | in 43,757 projects, so the original is retrievable
```

**Reference source:** GEO's per-sample characteristics fields. The comparison is exact — GEO either holds two or more distinct values for that field or it does not. No adjudication and no model are involved.

**Output:** a patch file of (project, sample, field, value, source), and a breakdown of loss by field and by year.

::: note accent=sky
**Week-one test.** Fetch 200 projects. Fewer than about 20 carrying extra values in GEO and the project stops; 60 or more and this is the largest recoverable gap identified.
:::

# A2 · ROSTER-AUDIT
## Papers containing a table of accessions

Some papers include a table listing each accession alongside its experimental condition. Where such a table exists, it can be compared against the archive record field by field. Each comparison falls into one of three classes:

```metrics accent=sky
Archive agrees with the paper | no action
Archive is coarser — one value where the paper gives several | the measurable class
Archive and paper conflict | rare; neither source is authoritative
```

The second class is the informative one. Two documents derived from the same source spreadsheet can conceal a difference in granularity but cannot create one — so this class is directional in a way the conflict class is not.

Papers commonly print accessions as a range, and a naive extractor keeps only the endpoints:

```text
paper prints    SRR36698137-SRR36698139
extractor kept  SRR36698137, SRR36698139      SRR36698138 silently lost
```

```stats accent=sky
701 | papers with a usable accession table | out of 136,323 in the linkage set
18,628 | samples covered by those tables | 
150 | papers hand-checked | to build the gold standard
```

::: note accent=amber
**Scale is the main caveat** and belongs in the first paragraph of any write-up, not a footnote. Extraction is a deterministic table parser, not a model. Cost is 15–25 person-hours of adjudication.
:::

# B1 · HIDDEN-CELL
## Recovery of withheld values from paper text

Select fields the submitter populated for some samples in a project and left blank for others. Withhold one populated value, supply the paper, and measure recovery.

```stats accent=purple
1,028,626 | values available to withhold | across 27,075 field-and-project combinations
524,391 | genuinely blank cells | the deployment target
15,147 | papers | all with full text on local disk
```

```text
PRJNA622707 — tissue populated on 21 of 27 samples
  Retina · Cornea · RPE            the 21 that have a value
  (blank)                          the other 6
```

The submitter clearly knew the field. Withhold one of the 21 and test recovery; the 6 genuine blanks are the deployment target.

**Control arm:** the same model without the paper. If accuracy is unchanged, paper text adds nothing over the archive record.

**Scoring:** residual cells only, per field, weighted per project and per submission batch, with both archive-only baselines reported as the floor.

::: note accent=rose
**Two limits on interpretation.** The measurement is recovery of *the value the submitter recorded*, not of ground truth. And blank samples are systematically thinner than populated ones — median 6 attributes against 9 — so held-out accuracy is an upper bound on deployment accuracy.
:::

# C1 · STRANDCHECK
## RNA-seq library strandedness

RNA-seq preparations either retain the strand of origin of each fragment or do not. Quantification requires the parameter; the wrong value produces incorrect counts for overlapping and antisense features.

Everything the archive records about run `DRR1000590`, an RNA-seq library:

```text
library_strategy  RNA-Seq          instrument_model  Illumina NovaSeq 6000
library_source    TRANSCRIPTOMIC   library_layout    PAIRED
library_selection PCR              nominal_length    400
```

Nothing there states whether it was stranded, and no field anywhere does — not among the 28 study, 103 sample or 186 run fields. Where recorded at all it sits in free-text protocol prose.

```stats accent=emerald
6,940,690 | RNA-seq runs archive-wide | 
2,593,143 | under a paper in the linkage set | across 66,500 projects
```

**Method:** pseudo-align 200k–500k reads against a reference transcriptome and measure orientation relative to annotated features. Stranded libraries place the large majority of reads on the expected strand; unstranded are close to even.

::: note accent=emerald
**Week-one test.** 200 runs whose protocol names a stranded kit, 200 naming an unstranded one. Failure to separate them indicates a problem with the method or the subsample size.
:::

# C2 · LAYOUT-TRIANGLE
## Paired-end versus single-end declaration

The archive records whether each run was read from one end of a fragment or both. A two-way comparison of record against data has been attempted and failed: the contradictions concentrate in one archive processing pipeline rather than at submission, so they say nothing about the deposit.

```metrics accent=emerald
Declared library_layout | source 1
File structure and read-name pairing | source 2
Read configuration stated in the paper methods | source 3
```

Adding the paper distinguishes the two cases. A processing artefact will not correlate with the paper text; a submission error will. The informative case is *record single, data paired, paper paired*.

```stats accent=emerald
33,535,627 | runs declared PAIRED | archive-wide
10,038,119 | runs declared SINGLE | archive-wide
1,635,719 | paired RNA-seq runs under a paper | against 957,424 single
```

::: note accent=rose
**Week-one test.** Take 300 runs where record and data already disagree and count how many of their papers state a read configuration. Below roughly 100, the third source is too sparse and this project should not proceed.
:::

# C3 · SELECTION-CHECK
## PolyA selection versus ribosomal depletion

Ribosomal RNA is removed before sequencing by one of two methods. **PolyA selection** retains polyadenylated transcripts only. **Ribosomal depletion** removes rRNA and retains the remainder, including non-polyadenylated and unspliced transcripts. The two capture different transcript populations and are not interchangeable.

What the archive actually records for `library_selection` on RNA-seq runs under a paper:

```text
cDNA          2,199,068     does not distinguish the two preparations
RANDOM           75,529     also uninformative
PCR              73,948     also uninformative
Oligo-dT         63,343     polyA selection
PolyA            57,583     polyA selection
```

Only the last two state which preparation was used. They form the calibration set; everything above them is the test set.

**Method:** two measurements from the same subsample as C1 — the fraction of reads originating from rRNA, and the fraction falling within introns. Ribosomally depleted libraries retain more intronic signal. Calibration uses the runs that declare a specific selection.

::: note accent=amber
**Confound.** Both measurements also vary with tissue, organism and RNA degradation. Calibration must be within tissue and organism. Pooled calibration measures RNA quality rather than library preparation.
:::

**Run with C1** — same download, same alignment, two additional measurements.

# C4 · TENX-DETECT
## Single-cell libraries labelled as bulk RNA-seq

Droplet-based single-cell protocols produce a characteristic read structure: one short mate of fixed length carrying a cell barcode and unique molecular identifier, paired with a longer mate carrying transcript sequence. This is detectable in the first few thousand reads.

A single-cell run labelled as bulk RNA-seq will be included in bulk reanalyses, where it is not interpretable.

```metrics accent=emerald
Search space | 2,593,143 RNA-seq runs under a paper
Number actually mislabelled | not measured
Prerequisite | measure it before allocating effort
```

The record cannot distinguish the two. A droplet run and a bulk run both appear as `RNA-Seq / TRANSCRIPTOMIC / PAIRED`, and mean read length does not separate them because it averages the short and long mates together. Only the per-mate structure does:

```text
mate 1    28 bases, fixed length, matches a barcode whitelist    droplet
mate 2    90-150 bases, transcript sequence
```

**Baseline to beat:** the declared `library_strategy` field, plus any mention of single-cell in the study title or free-text protocol. The residual — runs where neither states it — is the actual target.

::: note accent=amber
**Sizing step.** Apply the structural test to 5,000 RNA-seq runs and count those appearing single-cell where neither the strategy field nor the title indicates it. A residual in the low hundreds archive-wide makes this a defect report rather than a project.
:::

# C5 · TAXON-RATE
## Rate of incorrect species assignment

No current estimate exists. Two other proposals involved correcting species labels without a denominator for how often they are wrong.

```stats accent=emerald
5,436,008 | runs with usable assembly statistics | already computed and public
20,000 | drawn at random | capped per study, Illumina, non-metagenomic
0 | metadata inputs to the call | assignment is from sequence only
```

The declared organism is a free field on every run. The most common on whole-genome runs in one quarter of 2019:

```text
Salmonella enterica    32,859      Plasmodium falciparum   19,212
Escherichia coli       27,012      Campylobacter jejuni    16,168
```

None of these has ever been checked against the sequence.

**Method:** sketch Logan contigs and match against a reference genome database. Report the study-weighted fraction of runs whose assignment differs from the declared species, the fraction differing at genus level, and the fraction containing a second organism.

**Sampling is random, not flag-driven.** A genome-size flag does not work: of 12,523 *E. coli* runs flagged as oversized, **12,413 also had a fragmented assembly** — median contig length 126 bases against 11,239 for unflagged runs. The flag detects assembly failure. It also almost never catches the errors that occur, such as *E. coli* labelled as *Shigella flexneri*, because several genera fit inside one flag window.

::: note accent=emerald
**Week-one test.** 300 runs end to end. If disagreement is very rare at that scale, a 20,000-run sample gives an interval too wide to be useful; either increase the sample or restrict to fewer species.
:::

# C6 · KARYOCHECK
## Declared sex against sex-chromosome coverage

Count sequence fragments unique to the X and Y chromosomes in a few megabytes of each sample's data. The declared field is the quantity under test and is not used in the call.

**The unit of analysis is the donor, not the run.** Sex is a donor property inherited by every run from that donor:

```text
SAMN00006465   9,970 runs    PRJEB12849      one sample, one donor
SAMN00001695   9,675 runs    PRJEB12465
SAMN00001694   9,670 runs    PRJEB12465
```

Counting runs, those three records would carry the weight of 29,315 observations. They are three donors.

```stats accent=emerald
616,702 | runs fetchable and callable | 
107,564 | distinct biological samples | across 3,465 studies
```

Per-run counting is not valid — a single clerical error in one laboratory would move a per-run rate measurably on its own.

**Baselines:** caller error rate on reference samples down-sampled to the depth of the test set; the majority class, which shifts substantially once the six largest studies are removed; and prediction from other samples in the same study.

::: note accent=rose
**Exclusion, by design.** The four largest studies are almost entirely female single-cell amplified libraries examining chromosome loss. In amplified libraries the X/Y ratio reflects amplification dropout, not karyotype.
:::

# D1 · VOCAB
## Declared absence versus missing values

Fill rate — the proportion of fields containing a value — is the standard metadata quality metric. INSDC defines a controlled vocabulary for recording *why* a value is absent: `not collected`, `not applicable`, `restricted access`.

```metrics accent=amber
Submitter enters "not collected" | counted as populated
Submitter enters the actual value | counted as populated
Submitter leaves the field empty | absent from the denominator
```

A submitter following the standard is scored identically to one supplying the value. A submitter leaving the field empty does not enter the calculation at all.

What is actually in `collection_date` when it cannot be parsed as a date — 6,253,348 samples, 2,969 distinct strings:

```text
missing                        2,857,316
missing: third party data      1,097,390
not collected                    645,826
not provided                     598,684
not applicable                   596,948
```

Every one of these is a submitter following the standard. All are counted as populated.

::: note accent=amber
**Registry confound.** Absence terms are used far more by NCBI-registered samples than EBI-registered ones, while the underlying date-parse failure rate is flat across the same split. The difference reflects registry vocabulary conventions, not data quality. Cost: one 30-second scan.
:::

::: cards cols=2 gap=18px size=sm border=top
### Run as one job {accent=emerald}

**C1 and C3** use the same subsample and the same alignment. Running them separately doubles the download for no additional information.

### Keep implementations separate {accent=rose}

**A1 and A2** estimate the same quantity by different routes. This is useful only if they do not share code or a definition derived from each other.
:::

::: callout title="Bandwidth constraint" slim accent=rose
Measured aggregate throughput for read downloads is **1.0 MB/s** and does not increase with additional parallel connections. No more than two projects should download reads concurrently.
:::
